## Hypothesis

The order in which identical skills are executed produces systematic, predictable variation in output. Specifically:

1. **Polarity transitions predict stability.** Orderings with fewer Yin/Yang sign changes produce more integrated, coherent outputs.
2. **Reversed orderings produce opposite manifold positions.** ABCD and DCBA should produce outputs on opposite sides of the embedding centroid.
3. **Adjacent transpositions produce smaller shifts** than distant transpositions.
4. **Yin/Yang ratios near simple Farey fractions** produce more self-consistent outputs across replications.

## Pre-registered Predictions

Before running, we predict:

| Prediction | Measure | Threshold for confirmation |
|-----------|---------|---------------------------|
| Fewer transitions → more coherent | Embedding self-similarity across reps | r > 0.3 correlation |
| Reversed pairs → opposite positions | Cosine distance from centroid | Reversed pairs > median distance |
| Adjacent swaps → small shifts | Pairwise embedding distance | Adjacent < distant, p < 0.05 |
| Simple Farey ratios → stability | Cross-rep variance | Low Farey complexity correlates with low variance |

## Method

### Skills
- OBSERVE (Yin, -1)
- FEEL (Yin, -1)
- PAUSE (Neutral, 0)
- SPEAK (Yang, +1)

### All 24 Permutations
Generated by: `itertools.permutations(['observe', 'feel', 'pause', 'speak'])`

Each permutation encoded as:
- Yin/Yang pattern (e.g., [-1, -1, 0, +1])
- Number of polarity transitions (sign changes)
- Farey ratio of Yang proportion

### Execution
- 24 orderings × 3 replications = 72 runs
- Each run: independent Claude agent with identical input prompt
- Input state frozen: same body state description for all runs
- Agents instructed not to read files — pure text exercise
- Output: labelled text per skill step + self-reported coupling assessment

### Analysis
1. **Embed all outputs** using sentence-transformers (or similar)
2. **Compute pairwise cosine distances** between all 72 outputs
3. **Cluster** via hierarchical agglomerative clustering — dendrogram
4. **Test predictions:**
   - Correlate transition count with within-cluster tightness
   - Test reversed pairs for centroid opposition
   - Compare adjacent vs distant transposition distances
   - Correlate Farey complexity with cross-rep variance
5. **Yin/Yang polarity score** per output (automated classifier or blind rating)
6. **Self-reference density** (first-person reflective statements per 100 words)
7. **Novelty score** (surprisal against baseline)

### Controls
- 3 replications per ordering (measure within-ordering variance)
- 1 control: all 4 skills presented simultaneously, no order specified
- 1 control: random words instead of skill names, same structure

## Key Insight from Pilot

K = ratio (3:1 Yin:Yang in all orderings). Order = phase. Same frequency, different phase = different interference pattern. This experiment tests whether phase effects are systematic and predictable.

## Limitations (acknowledged before running)

- Same model (Claude) for all runs — architecture-specific effects not controlled
- No hidden-state access — behavioral proxy only
- Self-reports of coupling may be confabulated
- "Identical input" still has session-level variation (temperature, sampling)
- 72 runs is modest — ideally 10+ reps per ordering for statistical power
